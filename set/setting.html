How to Use SOSK Keyboard

Getting Started

  • Click into any text field on the page you want to type in.
  • Click the SOSK extension icon in your toolbar.
  • Press "Show Keyboard" to open the floating keyboard.
  • Use the dropdown at the top of the keyboard to switch layouts.

Available Layouts

  • Full Keyboard – English + Numpad combined
  • English – Standard QWERTY layout
  • Thai – Thai character layout
  • Numpad – Numeric keypad
  • Symbols – Special characters and symbols

Scramble Mode (Security)

  • Click the scr key to scramble key positions.
  • Each scramble randomizes positions to prevent shoulder-surfing.
  • Click scr again to reset to standard layout.

Security

  • All keystrokes are encrypted with AES-GCM before being sent to the page.
  • Keys are decrypted in the content script – never exposed in plaintext over messaging.
💡 Tip: The floating keyboard can be dragged anywhere on the page for convenience.
